Authentication
- User identified through unique individual email.

Authorization
- Users may belong to multiple committees.
- Users may chair one or more committees.
- Committee assignments change over time.
- Committee Chair can create/update reports for chaired committee.
- Other committee reports are view-only for standard users (TBD).
- President, VP1, VP2 and Technology Chair have full access.
- Authorized leadership can lock/unlock reports.

Reports
- Committee Report
- Post-Mortem Report
- Create new report
- Retrieve/update existing report
- Generate final PDF
- Export data to Excel
- Upload images/attachments
- Locked reports become read-only.

Templates / Questions
- Administrators manage report templates.
- Questions are versioned.
- Existing answers remain associated with the original question version.

Phase 2
- Browser-based reporting dashboard
- Search/filter by committee, event, reporting period, etc.
- Aggregate/report across historical data
- Role-based access to analytics
- Excel export remains available
